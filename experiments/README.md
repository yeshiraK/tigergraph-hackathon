# Experiments & Benchmarks

This directory houses experiment definitions, baseline configurations, execution traces, and comparison results.

## Subdirectories
- `baselines/`: Benchmark configurations and hyperparameters for RAG, GraphRAG, and Agentic GraphRAG.
- `runs/`: Execution traces and per-run telemetry logs (git-ignored).
- `results/`: Aggregated benchmark metric outputs, scorecards, and analysis tables (git-ignored).
