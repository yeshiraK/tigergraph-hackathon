# Layer 3: Specialists and MCP Tools

Responsible for exposing retrieval and graph capabilities via the Model Context Protocol (MCP):
- TigerGraph MCP server client and tool bridges.
- Specialized retrieval tools (vector search, GSQL queries, subgraph extractors).
- Evidence extraction tools.
- Strict constraint enforcement: tools interface exclusively with the local corpus and TigerGraph store.
